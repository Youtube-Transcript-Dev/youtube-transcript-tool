# Fetch transcript

Extract the transcript for a YouTube video.

## Usage

Provide a YouTube URL (e.g. `https://www.youtube.com/watch?v=dQw4w9WgXcQ`) or video ID.

## Options

- **Format**: txt (default), srt, vtt, json
- **Language**: ISO 639-1 code (e.g. en, es) or "auto" for original

## Example

```
Fetch transcript for https://www.youtube.com/watch?v=dQw4w9WgXcQ
```
